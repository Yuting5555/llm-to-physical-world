## 这是什么

一份 94 页、约 5.8 万字的**判断框架**，不是行业综述，也不是投资建议。

它只回答四个问题：

1. **进到哪了**——哪些领域已经进入物理世界、哪些正在进入、各自进到多深
2. **为什么是这个次序**——决定深度的机制是什么，中国的国情与体制怎么改变这个次序
3. **看什么指标**——先行、当期、滞后三类，分开用
4. **怎么跟**——每个决定本质上都是拿一种付出去换另一种，而你手里只有五种"货币"：钱、时间、注意力、风险、选择权。八类决策分别怎么跟

## v2026.09.03 改了什么：一条轴拆成两条

**如果你手上是 v2026.08.30，请注意：部分项目的坐标变了，那不是前后矛盾，是尺子换了。**

旧版用一条 D1–D4 轴同时量两件事——"要不要人盯着"和"部署有多深"。这两件事会分家，而且经常反着走，硬塞进一条轴就会把它们抹平。这一版拆成两条：

| | 量什么 | 谁归它 |
|---|---|---|
| **T0–T4**　技术闭环成熟度 | 从离线感知，到有人监督的闭环，到**写明边界内的自主闭环** | 自主性、接管率、纠偏与安全退出 |
| **D1–D4**　部署成熟度 | 从演示，到付费试点，到生产部署，到**可复制扩散** | 付费、同客户复购、跨场地复制、责任安排 |

坐标统一写成 `T?/D?`。两条轴不能互相代替，也**不可平均、不可相加**：

- **T1/D4**——产线视觉质检：技术并不新，但已在成百上千个场地稳定使用，验收与责任早就标准化
- **T3/D2**——展厅人形机器人：能在监督下做出一整套动作，但没有生产性复购
- **T4/D2**——技术闭环做成了，却没人复购

旧版的单轴分不开上面这两类，而市面上绝大多数误判正好就出在这里：一边高估人形，一边看不起质检。

三条配套的硬约束：

1. **T 不是"技术先进度"**。用了几十年的 PLC 在封闭产线上可以是 T4；会生成漂亮动作方案的通用大模型，如果动作还要人逐条批准，只能是 T2 或 T3。跨场景泛化也不塞进 T4——T4 只承诺"在写明的运行边界内闭合"，迁移成本另记。
2. **标 T4 必须写运行边界，标 D4 必须写风险容器**（无需对冲／围栏与安规／采购方自留／商业保险／制度化分摊）。容器不同的 D4 不是同一个 D4，不能相加成"行业完成度"。
3. **两条轴都写了退出条件**。只能往上爬的刻度是宣传梯子，能往下掉的才是尺子。

**跟着变的判读**：传统遥操作外科 → 约 `T1/D4`（技术很老，责任安排早已成熟）；晶圆厂样本 → `T4/D4`；算力资本周期不再误标 D4，改记为上游基线；增强路线的**人机杠杆倍数 1:N** 升为第三个独立读数，不与 T/D 平均。

第十四节新增了针对这套坐标自身的反驳：**二维坐标仍可能制造假精度**——这是本书自认最致命的一处。

## 它和别的同题材内容不一样的地方

三条自我约束，贯穿全书：

- **每一处数字都标来源性质**：监管数据／同行评审／第三方估算／当事方口径／媒体转述
- **每一处观点都标它是什么**：〔事实〕〔推断〕〔判断〕三级标注
- **写出证伪条件**：最后一节列出这套框架最可能错在哪，以及观察到什么就该推翻它

> 不写证伪条件的判断，等于没有判断。

## 参与方式：帮我证伪

这份东西的价值不在于预测准，而在于**能算出自己错在哪、错多少**。所以最欢迎的贡献不是点赞，是反证：

- 🔴 **[提交证伪](../../issues/new?template=falsification.yml)**——你有证据表明某个判断错了
- 🟡 **[提交口径纠错](../../issues/new?template=correction.yml)**——某个数字的口径、来源或日期有问题

被采纳的会记进 [ERRATA.md](ERRATA.md)，署名保留（除非你要求匿名）。
